## 남는 Mac을 공유 파일 서버로

데이터셋과 Git 프로젝트를 팀에서 한곳에 모아 쓰기 위해, Mac에 연결한 저장장치를 브라우저에서 관리하는 도구를 만들었습니다. 팀원은 파일을 올리고 내려받거나 Git 저장소를 복제할 수 있습니다.

## 업로드가 끊겨도 이어서 전송하기

대용량 파일을 32MB 단위로 나눠 병렬 전송하고, 업로드 세션을 디스크에 기록했습니다. 전송이 중단되면 이미 보낸 조각을 확인해 남은 부분부터 이어서 올릴 수 있습니다. 데이터셋을 사용하는 쪽에서는 HTTP Range로 필요한 범위만 요청할 수 있도록 했습니다.
