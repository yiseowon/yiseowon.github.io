## 로컬 모델에 필요한 도구를 붙이려고 시작

Ollama와 LM Studio를 사용하면서 모델의 실행 방식을 직접 제어하고 원하는 MCP나 도구를 연결할 수 있는 환경을 만들고 싶었습니다. 그 과정에서 로컬 모델이 macOS 화면을 보고 클릭 위치를 고르는 기능을 구현했습니다.

## 스크린샷과 실제 클릭의 좌표 맞추기

모델에 제공하는 스크린샷은 폭 1,280픽셀로 축소했지만, 모델이 반환한 위치를 실제 디스플레이 좌표로 해석해 클릭이 어긋났습니다. 모델 입력용 화면을 디스플레이의 포인트 해상도로 캡처해 macOS 클릭 이벤트와 좌표 기준을 맞췄습니다. 승인 카드에서만 이미지를 축소하고 클릭 위치에도 같은 축척을 적용했습니다.
